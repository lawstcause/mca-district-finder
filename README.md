# MCA Central Park · Find Your District

Live: **[https://lawstcause.github.io/mca-district-finder/](https://lawstcause.github.io/mca-district-finder/)**

Interactive map of Master Community Association delegate districts for Central Park, Denver (**80238**) and the Aurora edge of the community (**80012**).

Search an address, tap the map, or use your phone location to see which of the **11 MCA districts** you live in and who the current delegate is.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5174](http://localhost:5174).

```bash
npm run test:geo
npm run build
```

## What it shows

- 11 official MCA delegate districts (geometry from the official KMZ)
- Streets and satellite basemaps
- The official district key map in the sidebar

District polygons are a resident guide, not a surveyed legal plat.
